# Shifting to supervised topic assignment

This note makes the case for coding passages by hand in a sample of emails, sets out the objections to it, and describes a coding interface and codebook. `mockup.html` is the mockup of that interface, built with invented emails. I have since replaced this note with the [Study Design](https://zackbatist.info/CITF-emails/notes/study-design/).
